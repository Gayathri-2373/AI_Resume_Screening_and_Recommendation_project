AI Resume Screening & Job Recommendation System

Project Overview

           The AI Resume Screening & Job Recommendation System is a web-based application developed using Python and Streamlit. It automates the process of analyzing resumes, extracting skills, recommending suitable job roles, calculating job match scores, and identifying missing skills required for specific jobs.

Objectives

     Automate resume screening.
     
     Extract technical and soft skills from resumes.
     
     Recommend suitable job roles based on skills.
     
     Calculate resume-job matching scores.
     
     Identify skill gaps for career improvement.

Technologies Used
   
   Python
   
   Streamlit
   
   PyPDF2
   
   NLP (Natural Language Processing)
   
   Scikit-learn

Features

     PDF Resume Upload
     
     Resume Text Extraction
     
     Text Cleaning using NLP
     
     Skill Extraction
     
     Job Recommendation
     
     Match Score Calculation
     
     Missing Skills Detection
     
     Resume Strength Analysis
     
     Interactive Dashboard

Methodology
  
    Upload a resume in PDF format. 
    
    Extract text from the PDF.
    
    Clean and preprocess the text.
    
    Identify skills using predefined skill dictionaries.

    Recommend suitable job roles.

    Calculate match scores against required job skills.
    
    Display missing skills and resume strength.

Results

        The system successfully extracts skills from resumes, recommends relevant job roles, calculates match scores, and provides skill-gap analysis through a user-friendly interface.

Conclusion

    The project demonstrates the practical application of AI and NLP in recruitment processes. It helps job seekers understand their strengths and weaknesses while assisting organizations in automating resume screening.
